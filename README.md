# Paradise Nursery

Paradise Nursery is a responsive houseplant shop built with React, Vite, Redux Toolkit, and React Router. Browse 18 plants across three categories, add plants to the cart, adjust quantities, remove items, and review the order subtotal.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

## Main assignment files

- `src/App.jsx` — landing page and application routes
- `src/App.css` — landing background image and responsive styling
- `src/AboutUs.jsx` — company information
- `src/CartSlice.jsx` — Redux shopping cart state and selectors
- `src/ProductList.jsx` — categorized plant catalog
- `src/CartItem.jsx` — shopping cart page
